# 電卓ロジック（自分で1ステップずつ）

**いまできている:** 数字入力、`variant`、AC で表示 `"0"`（演算 state はまだリセットしない）

**進め方:** 1つ終わったらブラウザで確認 → 小さくコミット

---

## ステップ F-2: AC を全部リセット（演算 state を足したあと）

演算用の state を足したら、AC でそれらも初期値に戻す。

- `displayValue` → `"0"`
- `previousValue` → `null`
- `operator` → `null`
- `waitingForOperand` → `false`

---

## ステップ G: 演算子を1つ覚える（計算はまだしない）

1. `App.tsx` に state を2つ足す  
   - `previousValue` … `useState<number | null>(null)`  
   - `operator` … `useState<Operator | null>(null)`  
   - `import type { Operator } from "./types"`

2. 関数 `chooseOperator(op: Operator)` を作る（名前は自由）

3. 中身（最初はこれだけ）  
   - 画面の文字列を数値に: `Number(displayValue)`  
   - `setPreviousValue(その数値)`  
   - `setOperator(op)`  
   - `console.log` で確認

4. `+` ボタンの `onClick` を `() => chooseOperator("+")` に変える

**確認:** `7` → `+` → コンソール / React DevTools で `previousValue` が 7、`operator` が `"+"`

---

## ステップ G-2: 次の数字に切り替える

1. `waitingForOperand` … `useState(false)`

2. `chooseOperator` の最後で `setWaitingForOperand(true)`

3. `pushNumber` の**先頭**で  
   - `waitingForOperand === true` なら  
     - 表示を新しい1桁だけにする（`"0"` のときのルールは今までどおり）  
     - `setWaitingForOperand(false)`  
     - `return`（末尾に足さない）

**確認:** `1` → `+` → `2` で画面が `2`（`12` にならない）

---

## ステップ G-3: 計算関数（UIと分離）

1. `src/utils/calculate.ts` を新規作成

2. 関数の形（自分で中身を書く）  
   - `calculate(a: number, b: number, operator: Operator): number`  
   - `switch (operator)` または `if` で `+` `-` `×` `÷`  
   - `÷` で b が 0 のとき → `NaN` を返すなど方針を決める

3. **ボタンは触らず**、一時的に `App` やコンソールで  
   `calculate(1, 2, "+")` が `3` になるか確認

---

## ステップ G-4: `=` で1回計算

1. `handleEquals` を作る

2. `operator` または `previousValue` が `null` なら何もしない

3. そうでなければ  
   - `calculate(previousValue, Number(displayValue), operator)`  
   - 結果を `String(...)` で `setDisplayValue`  
   - 0除算 → 表示 `"Error"` など

4. `=` ボタンに `onClick={handleEquals}`

**確認:** `7` `+` `8` `=` → `15`

---

## ステップ H: 連続計算（`=` より前に演算子をもう一度）

`chooseOperator` の**最初**で:

- すでに `operator !== null` かつ `previousValue !== null` かつ `!waitingForOperand` なら  
  - 先に `calculate` して結果を画面に出す  
  - `previousValue` をその結果に更新

そのあといつもどおり新しい `operator` をセット、`waitingForOperand = true`

**確認:** `1` `+` `2` `+` の時点で画面 `3` → `3` `=` … ではなく `3` 入力後 `=` → `1+2+3=6` は `3` を押してから `=`

正しい確認: `1` `+` `2` `+` `3` `=` → `6`

---

## ステップ H-2: `=` のあと

`handleEquals` の最後:

- `setOperator(null)`  
- `setPreviousValue(null)`  
- `setWaitingForOperand(true)` … 次に数字を押したら新しい計算

**確認:** `10` `-` `3` `=` → `7`、続けて `+` `1` `=` → `8`

---

- キーワード: `useState`, `Number(displayValue)`, `waitingForOperand`

## このあと（追加機能の候補）

基本ロジックが動いたら、好きなものを1つずつ足す。順番は下の「おすすめ」どおりがやりやすい。

### おすすめ順

1. 計算履歴
2. バックスペース（⌫）
3. キーボード入力
4. 名言の再取得
5. ± / ％ / テーマ切替 など

---

### ステップ I: 計算履歴

`=` のたびに式と結果を残す。

1. state を足す  
   - `history` … `useState<string[]>([])`  
   - 例の1件: `"7 + 8 = 15"`

2. `handleEquals` の成功時に  
   - 文字列を組み立てて `setHistory((h) => [新しい1件, ...h])`  
   - 件数を上限（例: 5件）にするなら `.slice(0, 5)`

3. 電卓の下（または横）に `<ul>` で表示

**確認:** `7` `+` `8` `=` → 履歴に `7 + 8 = 15` が出る

---

### ステップ J: バックスペース（⌫）

1桁ずつ消す。

1. `backspace` 関数を作る  
   - `waitingForOperand` のときは何もしない（または無視）  
   - 1文字だけなら `"0"` にする  
   - それ以外は `displayValue.slice(0, -1)`

2. ボタン `⌫` を足して `onClick={backspace}`

**確認:** `123` → `⌫` → `12` → `⌫` → `1` → `⌫` → `0`

---

### ステップ K: キーボード入力

マウスなしで操作できるようにする。

1. `useEffect` で `window` に `keydown` を登録（クリーンアップで `removeEventListener`）

2. キー対応の例  
   - `0`–`9` → `pushNumber`  
   - `+` `-` `*` `/` → `chooseOperator`（`*`→`×`、`/`→`÷`）  
   - `Enter` または `=` → `handleEquals`  
   - `Escape` → AC と同じリセット  
   - `Backspace` → `backspace`（J を先にやっている場合）

**確認:** キーボードだけで `1` `+` `2` `Enter` → `3`

---

### ステップ L: 名言の再取得

いまはマウント時に1回だけ。計算やボタンで更新する。

1. `refreshQuote` 関数  
   - `getQuote().then((data) => setQuote(data.text))`  
   - 失敗時は今の名言のまま／短いエラー表示など方針を決める

2. どちらか（または両方）  
   - 「名言」ボタンで手動更新  
   - `handleEquals` の成功時に自動で `refreshQuote()`

**確認:** `=` またはボタン後に表示が変わる（API のランダム結果）

---

### ステップ M（任意）: 符号反転（±）

- `displayValue` を数値にして `-1` 倍し、文字列に戻す  
- `"0"` のときは何もしないでもよい

**確認:** `5` → `±` → `-5` → `±` → `5`

---

### ステップ N（任意）: ％

かんたん版で十分（本格電卓の％は仕様が複雑）。

- 例: 表示を `Number(displayValue) / 100` にして文字列化  
- **確認:** `50` → `%` → `0.5`

---

### ステップ O（任意）: エラー表示の改善

ゼロ除算などで `"Error"` のあと、次の数字入力で普通に再開できるようにする。

- `displayValue === "Error"` のとき `pushNumber` は新規入力扱い（`waitingForOperand` と同様）

**確認:** `1` `÷` `0` `=` → `Error` → `5` → 画面が `5`

---

### ステップ P（任意）: テーマ切替

明／暗など見た目だけ変える。

1. `theme` state（`"light" | "dark"` など）
2. ルートの `className` を切り替える
3. トグルボタンを Header 付近に置く

**確認:** ボタンで背景・文字色が切り替わる

---

### 詰まったとき（追加機能）

- 履歴・名言は「計算の成功時だけ」更新する（Error では増やさない）
- キーボードはブラウザのショートカットとぶつからないキーから始める
- 1機能 = 1コミット のまま続ける
